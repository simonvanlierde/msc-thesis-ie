Accessibility

This dashboard presents cooling demand and environmental impacts for buildings in The Hague.

Controls support keyboard navigation. A skip link reaches the main content, and visible focus shows the selected control.

Charts and maps have data tables. The page supports light and dark themes and reduced motion preferences.

Checks and limits

Automated axe checks test serious and critical WCAG 2.2 A and AA issues in both themes. They do not establish full conformance.

The interactive map supports pointer exploration; its table provides the neighbourhood values without using the map.

Screen reader use has not had a complete manual audit.

Report a problem

Report an accessibility issue with the page, browser and the action you could not complete.
